# Пиццерия

Консольное приложение на C# для демонстрации ООП: абстрактного класса, наследования, интерфейса скидок, коллекций и работы с заказом.

## Запуск

Нужен .NET 8 SDK или новее. В папке проекта выполните:

```bash
dotnet run
```

## Реализовано

- Абстрактный класс `MenuItem` и наследники `Pizza`, `Drink`, `Dessert`.
- Интерфейс `IDiscountable` с внешней скидкой и индивидуальными дополнительными скидками.
- Класс `Order`: максимум 20 позиций, проверка на `null`, чек, итоговая стоимость и расчёт скидки.
- Класс `Combo`: объединение позиций меню и скидка 15% на сумму входящих позиций.
- Поиск самой дорогой позиции и сортировка по цене.
- Настроенный `.gitignore` для .NET и файлов IDE.

Список позиций заказа возвращается как `IReadOnlyList<MenuItem>`, поэтому коллекцию нельзя изменить через это представление.
